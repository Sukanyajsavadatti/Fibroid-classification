# Fibroid-classification
AI-Based Fibroid Detection System using Deep Learning and Grad-CAM for ultrasound image analysis. The system detects fibroids, generates explainable heatmaps, performs morphological analysis, and creates automated clinical reports through an interactive Streamlit application.
## Dataset

**Classification Fibroid Dataset (Kaggle)**

🔗 https://www.kaggle.com/datasets/aureenblessingharazi/classification-fibroid

The dataset consists of ultrasound images belonging to two classes:
- Fibroid
- Non-Fibroid

The images were preprocessed and used to train a ResNet-50 based deep learning model for fibroid classification and Grad-CAM based lesion visualization.
